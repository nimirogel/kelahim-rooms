# חדרים להשכרה · קלחים

אתר עצמאי להזמנת חדרים ומתקנים במבני הציבור של מושב קלחים. פתוח לכל אחד, בלי הרשמה.

## מה יש באתר

- **לשוכרים:** בחירת חדר, לוח זמינות חודשי, הזמנה לפי שעה / שעות קבועות / 24 שעות, הזמנה חוזרת, תעריף תושב קלחים / תושב חוץ, ביטול לפי תנאי הביטול, הזדכות עם תמונות להחזרת פיקדון, לוח השכרות כללי.
- **למנהל:** לוח כל ההשכרות, הזמנות ותזכורות בוואטסאפ, סימון תשלום, החזרים, בדיקת הזדכויות והחזרת פיקדון, הזמנה ידנית, וכל ההגדרות (מבנים, חדרים, מחירים, שעות, מוצ״ש, נהלים, לוגו ותמונות).
- **אבטחה:** המחיר מחושב בשרת. המסד עצמו חוסם הזמנות חופפות (כולל זמן ההפרדה). פרטי השוכרים גלויים רק למנהלים. כל שוכר מקבל קישור אישי להזמנה שלו.

## מבנה התיקייה

```
web/                 האתר עצמו (מה שעולה ל-Netlify)
  index.html
  app.js             מסכי האתר
  api.js             החיבור למסד (או מצב הדגמה)
  config.js          כאן מדביקים את פרטי Supabase
  styles.css, logo.webp, demo-settings.json
supabase/
  schema.sql         טבלאות, פונקציות והרשאות
  storage.sql        תיקיות התמונות
  seed.sql           החדרים, המחירים והנהלים של קלחים
tests/db.test.mjs    בדיקות למסד הנתונים
netlify.toml         הגדרות פרסום
```

## אפשר לראות את האתר מיד

כל עוד `web/config.js` ריק, האתר רץ **במצב הדגמה**: נתוני דוגמה שנשמרים רק בדפדפן. כניסת מנהלים במצב הדגמה עובדת עם כל אימייל וסיסמה.

## הקמה (פעם אחת, כ-30 דקות)

### 1. Supabase: מסד הנתונים

1. נכנסים ל-[supabase.com](https://supabase.com) ← **Start your project** ← נרשמים (חינם).
2. **New project**. שם: `kelahim-rooms`. אזור: **Frankfurt (eu-central-1)**. שומרים את סיסמת המסד במקום בטוח.
3. בתפריט: **SQL Editor** ← **New query**. מדביקים את כל התוכן של `supabase/schema.sql` ← **Run**.
4. שוב **New query**: מדביקים את `supabase/storage.sql` ← **Run**.
5. שוב **New query**: מדביקים את `supabase/seed.sql` ← **Run**. (זה טוען את כל החדרים והמחירים.)

### 2. משתמש מנהל

1. בתפריט: **Authentication** ← **Users** ← **Add user** ← **Create new user**. אימייל וסיסמה של המנהל. מסמנים **Auto Confirm User**.
2. **SQL Editor** ← **New query**, ומריצים (עם האימייל של המנהל):
   ```sql
   insert into public.admins (user_id, email)
   select id, email from auth.users where email = 'manager@example.com';
   ```
   חוזרים על זה לכל מנהל נוסף.
3. מומלץ: **Authentication** ← **Sign In / Providers** ← **Email** ← לכבות **Allow new users to sign up**, כדי שרק מנהלים שהוספתם יוכלו להיכנס.

### 3. חיבור האתר למסד

1. ב-Supabase: **Project Settings** ← **API**. מעתיקים את **Project URL** ואת המפתח **anon public**.
2. פותחים את `web/config.js` ומדביקים:
   ```js
   window.KELAHIM = {
     supabaseUrl: "https://xxxxxxxx.supabase.co",
     supabaseAnonKey: "eyJ..."
   };
   ```
   המפתח הזה ציבורי מטבעו ומותר לפרסם אותו. ההגנה היא בהרשאות שבמסד.

### 4. פרסום האתר (GitHub Pages)

האתר מתפרסם אוטומטית מהמאגר ב-GitHub: כל שינוי שנדחף לענף `main` עולה לאוויר תוך דקה-שתיים (ההגדרה בקובץ `.github/workflows/pages.yml`).
כתובת האתר: **https://nimirogel.github.io/kelahim-rooms/**

לכתובת משלכם (למשל `rooms.kelahim.co.il`): במאגר ב-GitHub ← **Settings** ← **Pages** ← **Custom domain**, ולפי ההוראות שם.
(אפשר גם Netlify: גוררים את תיקיית `web` ל-app.netlify.com/drop.)

### 5. בדיקה

1. נכנסים לאתר ← **כניסת מנהלים** (למטה) ← האימייל והסיסמה מסעיף 2.
2. בודקים בהגדרות: וואטסאפ של המנהל, קישור התשלום לכל חדר, שעות הפעילות.
3. מבצעים הזמנה לדוגמה מהטלפון, ומבטלים אותה מ״ההזמנות שלי״.

## עדכון האתר בהמשך

- **מחירים, חדרים, שעות ונהלים:** מתוך מסך הניהול באתר. לא צריך לגעת בקוד.
- **שינויי קוד:** דוחפים ל-`main` ב-GitHub, והאתר מתעדכן לבד.

## מה עוד לא נבנה (השלבים הבאים)

- **תשלום מאושר אוטומטית:** חיבור Invoice4U כך שהזמנה תסומן ״שולם״ לבד.
- **תזכורות אוטומטיות:** SMS / אימייל יום לפני, בלי לחיצה של המנהל.
- **אימות טלפון ב-SMS** לפני הזמנה.
- **בדיקת שעות פעילות בשרת:** כרגע האתר מציג לשוכר רק שעות פתוחות, אבל השרת עצמו לא חוסם הזמנה מחוץ לשעות (מישהו שעוקף את האתר יכול). המנהל רואה כל הזמנה ויכול לבטל.
